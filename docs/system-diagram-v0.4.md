# Authorial Agent system diagram v0.4

This revision makes the author's stage-specific requirement explicit:

| Stage | Role of rules and exemplars |
| --- | --- |
| Construction | Conceptual and epistemic rules with actual examples shape the encoded intellectual work. Rhetorical purposes and act order are planned here. |
| Construction review | Check the demonstrated pattern and the concrete decision it shaped in claims or acts, along with evidence and scope. |
| Expression | Rhetorical and linguistic rules with actual examples guide prose that realizes the closed construction. |
| Four-layer checking | Compare the exact prose with the constructed content and the relevant rule/example applications. |

the observed prompt difference, metadata projection correction and limitations.

connections do not imply that a new paragraph passed or that the author approved
